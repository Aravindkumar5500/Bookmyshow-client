# Movie Booking UI — Educational Prototype

A small, static movie-listing and booking-interface prototype inspired by movie-ticket platforms. This is an independent learning project and is not affiliated with BookMyShow.

## Current UI

- Responsive navigation and movie listing layout
- Movie detail page
- Client-side scripts for loading movie data and handling interactions
- Bootstrap-based styling

## Run locally

Open `index.html` through a local static server, for example:

```bash
npx serve .
```

The page expects the companion API to be configured in the frontend scripts.

## Related backend

- [Bookmyshow-backend](https://github.com/Aravindkumar5500/Bookmyshow-backend)

## Scope

This repository is a learning prototype, not a production ticketing platform. Real payments, seat locking, concurrent booking protection, account security, and production deployment hardening are outside the current documented scope.
